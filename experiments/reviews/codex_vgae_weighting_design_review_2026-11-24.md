**BLOCKER — The strict text constraint is violated indirectly by parameter selection and adaptive attacks.** [run.py:241](</G:/broswer download/STEM-GNN/STEM-GNN/scripts/vgae_weighting/run.py:241>) selects `tau` and `eps` using validation accuracy from a model that reads MiniLM features; changing text can therefore change the selected edge weights. The scorer itself takes only graph structure and continuous attack weights. **Fix:** predeclare fixed weighting parameters or select them using a text-independent procedure. Explicitly resolve whether attacker-selected edges are exempt from the constraint; if text must *never* select edges, the current adaptive suite is incompatible and needs a text-free attack objective.

**BLOCKER — Jaccard inside PRBCD is likely prohibitively expensive and may exhaust memory.** [run.py:121](</G:/broswer download/STEM-GNN/STEM-GNN/scripts/vgae_weighting/run.py:121>) builds an \(N\times N\) dense adjacency and multiplies a sparse candidate adjacency by it on every forward/backward. PRBCD uses 100,000 candidate pairs and 100 epochs; the 10 S-SJ attacks per cell repeatedly perform this operation, including gradients. The clean-graph gradient check does not test this workload. **Fix:** benchmark a complete S-SJ attack at the actual block size on a cluster CPU allocation, including peak RSS and wall time; implement and validate a scalable differentiable alternative or reduce the block under a newly declared attack protocol. Do not launch the full grid until it completes.

**BLOCKER — The inferential unit is overstated.** [protocol.md:45](</G:/broswer download/STEM-GNN/experiments/vgae-weighting/protocol.md:45>) and [protocol.md:54](</G:/broswer download/STEM-GNN/experiments/vgae-weighting/protocol.md:54>) repeatedly evaluate the same graph and three overlapping splits, yet [analyze.py:79](</G:/broswer download/STEM-GNN/STEM-GNN/scripts/vgae_weighting/analyze.py:79>) treats 10 graphs or 15 split/seed cells as independent observations in paired t-tests.
