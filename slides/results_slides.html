Motivation
GNNs Degrade Under Structural Distribution Shift
Node representations depend on graph neighborhood — so the same node can look different under degree or homophily shift. Five benchmarks stress-test different failure modes.
5 OOD Benchmarks

Core Problem: Expert Collapse
Without entropy regularization: router assigns ~100% nodes to one expert (max_usage ≈ 1.000). MoE collapses to a standard GNN — no benefit from multiple experts, no specialization.
With λenv = 0.1: Layer 0 max_usage drops to 0.62 ± 0.16. Experts genuinely specialize. TV distance ID→OOD < 0.05 — routing distribution stays stable under shift.
LLM-direct routing (new): Instead of routing on GNN hidden states (which change with graph structure), route on frozen 768-dim text embeddings. Hypothesis: same semantic content → same expert, regardless of neighborhood topology.
Method
STEM-GNN: Pre-trained Sentence Embeddings + MoE Encoder
The LLM is used offline only — it produces fixed 768-dim embeddings per node. The GNN then learns over these frozen features during pretrain and finetune.

Summary
Key Findings
① Entropy reg is essential
λenv = 0.1 drops max_usage from 1.000 → 0.62. Without it, MoE is just a single GNN. This is the most impactful change.
② STEM-GNN generalizes well on Pubmed
Degree shift: only 1.7% ID→OOD-low gap. Routing shift TV < 0.05 confirms the model's routing distribution barely changes under structural OOD.
③ Homophily OOD-high often exceeds ID
Pubmed: 91.96% OOD-high vs 89.73% ID. High-homophily nodes are "easier" — cleaner neighborhoods amplify the GNN's aggregation signal.
④ WikiCS harder: 10.4% OOD-low drop
Low-degree nodes have little neighborhood info. High variance (±2.5–5%) from 10-class stratification. Arxiv will provide cleaner large-scale signal.
⑤ LLM-direct router ≈ GNN router in accuracy
Structure-invariant routing on frozen text embeddings matches GNN routing to within 0.14% OOD accuracy. The entropy regularizer drives robustness, not the router input type.
⑥ GNN router achieves higher expert class purity
Cora L1: 0.456 (GNN) vs 0.357 (LLM). Message-passing naturally clusters semantically similar nodes — the GNN hidden state already carries structural class information that the frozen text embedding lacks.
