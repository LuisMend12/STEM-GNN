02 / 11
Motivation

GNNs are vulnerable to semantically camouflaged edge attacks

The Attack

Inject edges between nodes that are semantically similar (LLM cosine ≥ 0.5) but belong to different classes. At 50% ratio, up to N such confusing edges enter the graph.

Why standard defences fail
  • GAT learns attention on the corrupted graph → reinforces injected edges (−10.7pp Cora, −13.5pp PubMed)
  • GCN symmetric normalisation amplifies injected degree (−7.5pp / −12.5pp)
  • RobustGCN designed for structural attacks, breaks on semantic camouflage (−5.5pp / −12.5pp)
  • GNNGuard uses BOW cosine — the same signal the attack exploits (−3.3pp / −9.2pp)
Key insight: Any defence using in-graph topology or feature similarity can be fooled by a similarity-constrained attack. We need a frozen external semantic oracle with no gradient path through the corrupted graph.

Novel Methods — Subgraph Fusion

Six new architectures targeting robustness at the aggregation step

R — LLM-GAT

Per-edge attention computed from frozen LLM cross-attention. Each e(u,v) gets a trust weight independent of the BOW training signal.

w(u,v) = softmax( q(u)·k(v)/√d )
S — LLM-APPNP ★

APPNP propagation where per-node teleportation is replaced by LLM variance gate βv. Uncertain nodes stay local; coherent nodes propagate.

h ← (1−β)·Ãh + β·h₀
T — MoE Fusion

Three expert aggregators (mean / max / LLM-attn) routed by gate signals O, P, Q via a learned gating network.

r = softmax( Linear([s_O, s_P, s_Q]) )
U — LLM Trimmed Mean ⚠

Drop bottom-20% neighbours by LLM cosine. Backfires: the attack injects high-cosine edges, so trimming keeps injected edges and discards legitimate low-cosine ones. −8.4pp Cora, −9.8pp PubMed.

V — LLM Consensus

Aggregate only neighbours whose LLM proto prediction matches node v's class. More effective on PubMed (3 clear classes) than Cora (7 fine-grained CS subfields where proto accuracy ~13%).

W — LLM Multi-Scale

Fuse 1-hop and 2-hop subgraph embeddings via the variance gate βv. High β → trust 1-hop only. Moderate robustness but slightly worse than SAGE on both datasets.

Key Insight

Neighbourhood incoherence, not similarity, is the right robustness signal

Why similarity signals backfire

The attack selects node pairs with cosine ≥ 0.5. Any signal that asks "how similar is v to its neighbourhood" will report high alignment — precisely because the attack guarantees it.

cosine (A): −8.2pp Cora, −12.3pp PubMed
max_cosine (E): −9.6pp / −12.3pp
topk (H): −7.0pp / −11.0pp
GNNGuard (BOW cosine): −3.3pp / −9.2pp
Why uncertainty signals work

Even when every injected edge is individually high-cosine, mixing wrong-class nodes into a neighbourhood creates spread across clusters in LLM embedding space — detectable as variance, entropy, or spectral incoherence. This signal cannot be suppressed without also making the edges obviously different-class.

spectral (Q): +0.4pp Cora, −1.0pp PubMed
energy_dist (P): −0.2pp / +0.2pp
variance (D): +1.5pp / −1.0pp

Clean accuracy vs robustness trade-off:
Graph-heavy methods (LLM-GAT, MoE Fusion: ~79–81% clean) drop 6–7pp under attack. Uncertainty gates (~58–74% clean) are near-immune.

LLM-APPNP bridges the gap — it uses the LLM variance gate as per-node teleportation in APPNP, giving competitive clean accuracy (60.1% Cora, 75.5% PubMed) with near-immune robustness (−1.2pp / −2.7pp).

Why a frozen external oracle is crucial
  • No gradient path through the attacked graph — gate signal is fixed at inference time, cannot be poisoned
  • BOW (1433-d) and LLM (768-d) are independent feature spaces — attack must fool both simultaneously
  • Key negative result: LLM Trimmed Mean (U) shows that LLM-based similarity filtering is also exploitable if the attacker controls the similarity distribution

Conclusion

A frozen LLM as an out-of-band semantic oracle — attack-invariant by construction

What we showed (Cora + PubMed, 30 methods each)
  • Frozen LLM gate signals cannot be poisoned — no gradient path through the attacked graph; the gate is fixed at inference
  • Uncertainty/spread signals (D, O, P, Q) are near-immune to semantic injection: ≤ 2.4pp drop across both datasets
  • LLM-APPNP is the best robustness–accuracy trade-off: −1.2pp Cora, −2.7pp PubMed vs GNNGuard's −3.3pp / −9.2pp
  • Similarity-based signals backfire — cosine, max_cosine, topk, GNNGuard all exploit the same signal as the attack
  • RobustGCN collapses on PubMed (−12.5pp) — designed for structural attacks only
  • LLM Trimmed Mean is a key negative result — similarity-based LLM filtering is also exploitable (−8.4pp / −9.8pp)
Future work
  • OGBN-Arxiv results (currently running)
  • Adaptive attacks that jointly optimise semantic cosine and class confusion
  • Larger LLMs (LLaMA-3, Mistral) as gate signal providers
  • Learnable per-dataset gate signal selection
  • Graph-level classification and link prediction tasks
  • Theoretical characterisation: when does neighbourhood incoherence provably detect adversarial edges?

Core message: The frozen LLM acts as an out-of-band semantic oracle — independent of the training graph, attack-invariant, scalable to any text-attributed node. Measuring uncertainty over the oracle's neighbourhood distribution is the right robustness signal.
