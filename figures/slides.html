The Attack

Semantic Injection — A Camouflaged Poisoning Attack

inject edge (v, u) if
  cosine(zv, zu) ≥ 0.5 ← high LLM similarity
  label(v) ≠ label(u) ← wrong class
at ratio r = 0%, 10%, 20%, 30%, 50%
Why it's hard: The injected edges look legitimate by the cosine similarity metric that most defences rely on — yet they carry the wrong class signal into the neighbourhood aggregation.
Effect: Standard GCN drops −5.0pp, GAT drops −10.7pp on Cora at r=50%. GNNGuard — which uses cosine similarity as trust — drops −3.3pp despite being a dedicated robustness method, because it rewards high-cosine edges.
Attack at r = 50%
  • Up to 0.5 × N new edges injected
  • Each edge has LLM cosine ≥ 0.5 to the target
  • All edges cross class boundaries
  • Injected using frozen LLM embeddings — attacker uses same encoder

Method

The Semantic Trust Gate

hv = βv · Wself(xv) + (1 − βv) · Wneigh(meanu∈N(v) xu)

βv = gate_signal(zv, {zu}u∈N(v))
z = frozen DistilBERT embeddings (768-dim, multi-qa-distilbert-cos-v1)
Why frozen embeddings?
  • βv → 1: trust self, ignore neighbours (gate fires)
  • βv → 0: trust neighbourhood (gate silent)
  • No gradient path through attacked graph — gate cannot be poisoned
  • Embeddings pre-computed once; zero training overhead
Encoder

multi-qa-distilbert-cos-v1 — 66M parameter sentence transformer, 768-dim output. Used for both gate signals and class prototype computation. Never fine-tuned — frozen throughout all experiments.

GraphSAGE 2-layer backbone
Layer 1: [BOW → 128] with gate β computed from LLM embeddings
Layer 2: [128 → 128] gate recomputed (same frozen LLM)
Output: [128 → C] linear classifier

Optimizer: Adam lr=5×10−3, wd=5×10−4, 150 epochs, early stop on val.

Core rule
Uncertainty signals are near-immune. The semantic injection attack requires cosine ≥ 0.5 — but wrong-class nodes spread across multiple LLM class clusters. Even if each edge looks similar, the neighbourhood as a whole becomes incoherent in embedding space. Variance/spectral/energy gates detect exactly this.
Why similarity signals backfire
The attack's own constraint (cosine ≥ 0.5) is what similarity gates use to assign high trust to edges. GNNGuard, cosine-gate, max-cosine-gate all reward the attack for satisfying their trust criterion.
Ensemble D+P+Q — best of both worlds

Average β from variance (D), energy_dist (P), and spectral (Q). Achieves 79.8% clean / −1.6pp Cora and 80.0% clean / −4.4pp PubMed — high accuracy AND robustness simultaneously.

Semantic (our main attack)

Inject wrong-class edges with cosine ≥ 0.5. Camouflaged — uncertainty gates near-immune (+1.5pp to −1.6pp).

Random injection

Inject random wrong-class edges (no cosine filter). Neighbourhood variance explodes → variance gate fires maximally → model becomes MLP. GraphSAGE loses −21.6pp; variance gate collapses −16.3pp.

Adaptive injection (self-defeating)

Attacker tries to minimise variance increase while injecting. The constraint "wrong-class + cosine ≥ 0.5 + low variance" is nearly unsatisfiable → near-zero drops across all methods.

Novel Gate Signals · X1–X4

Four New Uncertainty Signals from LLM Knowledge

X1 — Proto-Entropy Robust ✓
βv = H(softmax(zv @ PT / τ)) / log(C)

Entropy of v's distribution over class prototypes. High entropy = sits on class boundary = distrust neighbourhood. Cora: +1.1pp / PubMed: −0.5pp

X2 — Proto-Disagree Backfires on Cora
βv = 1 − sim(z̄N(v), Ppred(v))

High when neighbourhood centroid contradicts v's LLM class. Under semantic injection (cosine ≥ 0.5) the centroid still points near v's class — gate misfires. Cora: −9.1pp

X3 — Contrastive MLP Splits by dataset
βv = 1 − mean f(zv, zu) for u ∈ N(v)

2-layer MLP trained on labelled same/diff-class node pairs. Works on 3-class PubMed (−1.0pp) where MLP learns clean; fails on 7-class Cora (−11.1pp) where labeled edge pairs per class are too sparse.

X4 — MI-Approx Moderate
βv = 1 − cos(zv, z̄N(v))²

1 minus the coefficient of determination of neighbourhood centroid vs node embedding. Under attack the centroid drifts even when individual edges have high cosine. Cora: −1.4pp / PubMed: −4.2pp

What they all miss
None leverage a frozen, attack-immune semantic encoder. All prior defences either (a) use graph structure alone, (b) use features that can be poisoned through training, or (c) use cosine similarity that the semantic attack directly exploits.

Our key insight: a frozen LLM encoder provides an out-of-band signal that cannot be manipulated by edge injection — no matter what edges are added, the LLM embedding of any node remains fixed.
The semantic attack's specific blind spot
GNNGuard and cosine-based defences are actively exploited by the semantic injection attack — which requires high cosine precisely to bypass them. A defence that rewards cosine similarity is exactly what this attack was built to fool.

Novel Contributions · Literature × Our Gate

Four Novel Combinations — Taking Each Prior Method Further

Y1 — SVD-VarGate GCNSVD × Variance Gate Entezari WSDM'20

Truncated SVD scores every edge by its reconstruction value in the top-20 singular vectors. Adversarial edges violate the class-block low-rank structure → negative score → pruned. Variance gate then catches residual semantic noise. Two orthogonal filters: spectral structure + LLM semantics.

Y2 — ElasticGate ElasticGNN × Variance Gate Liu ICML'21

Replace mean with L1-proximal aggregation: elastic(x̄) = sign(x̄)·max(|x̄|−λ, 0). Adversarial neighbours pull the mean in wrong coordinate directions — L1 clips each coordinate. Variance gate adds the second semantic layer. Outlier coordinate suppression + neighbourhood incoherence.

Y3 — ProtoClean Pro-GNN × LLM Prototypes Jin KDD'20

One-shot structure learning: compute class prototypes from train-node LLM embeddings, predict each node's class, prune edges where endpoints predict different classes. Then variance gate on cleaned graph. O(N·C) — no expensive iterative optimisation. Adversarial edges are wrong-class → removed.

Y4 — RobustGCN-LLM RobustGCN × LLM Variance Zhu KDD'19

Augment RobustGCN's learned variance attention with frozen LLM gate: w(u→v) = exp(−σ²_u) · (1−β_u). Learned σ² can be poisoned via training; frozen β cannot. Two independent uncertainty sources: one adapts to data, one is invariant to the graph.

Analysis

Why Frozen LLM Uncertainty Is Attack-Immune

The attack's constraint creates its own detection signal

The semantic injection requires cosine ≥ 0.5 AND wrong class. To satisfy cosine ≥ 0.5, the adversary must pick nodes that live in the boundary region between two LLM class clusters — nodes where the embedding is ambiguous between classes.

These boundary-region wrong-class nodes spread the neighbourhood's LLM embedding over multiple class clusters simultaneously — exactly what the variance gate measures.

Why similarity gates fail

The attack requires cosine ≥ 0.5. GNNGuard's trust criterion is cosine ≥ threshold. The attack was designed to fool exactly this. Every adversarial edge receives maximum trust from a cosine-based defence.

Why uncertainty gates win
  • Adversarial nodes are from wrong class → their embeddings cluster differently
  • Even if cosine to v is high, they don't cluster with each other
  • Neighbourhood variance in LLM space increases regardless of individual cosine scores
  • Frozen encoder: no gradient path → gate can't be poisoned at train time
Robustness-accuracy trade-off
Key principle

Any gate signal derived from the distribution of a node's neighbourhood (variance, spectral, entropy) is robust to semantic injection. Any gate derived from individual edge similarity is exploited. The distinction is local incoherence vs local similarity.

Conclusion

Key Findings & Future Directions

What We Found

  • Uncertainty gates are near-immune to semantic injection. Variance, spectral, energy_dist: −0.2pp to +1.5pp on Cora at r=50%.
  • Similarity gates backfire: GNNGuard −3.3pp, cosine gate −8.2pp, GAT −10.7pp. The attack exploits the trust criterion.
  • Ensemble D+P+Q achieves 79.8% clean / −1.6pp Cora, 80.0% / −4.4pp PubMed — best combined accuracy and robustness.
  • Heterophilic auto-adaptation: gates fire β→1 by default, spectral +5.4pp Cornell under attack.
  • Scale holds: energy_dist +1.6pp on 169k OGBN-Arxiv nodes.
  • Novel combos: SVD-VarGate 0.0pp drop, ElasticGate +3.5pp gain (Cora).
Core insight: A frozen encoder provides an attack-immune signal. Neighbourhood incoherence in LLM embedding space is the key: high-cosine wrong-class nodes still spread the neighbourhood across class clusters, detectable as variance.
