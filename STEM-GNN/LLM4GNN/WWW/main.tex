\title{Robust Graph Learning with Fallible LLM Relation Evidence}

\author{Anonymous Author(s)}

\begin{abstract}
Language models can provide semantic evidence about relations in text-attributed graphs, but
adversaries can manipulate both graph structure and the node text from which this evidence is
derived. We study how graph neural networks can use such fallible evidence without amplifying its
errors.
\end{abstract}

\keywords{graph neural networks, large language models, graph robustness, adversarial attacks}
