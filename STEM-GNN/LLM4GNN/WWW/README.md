# WWW manuscript

This directory uses the official ACM proceedings template required by The Web Conference Research
Track. The review manuscript is double-column and anonymous:

```latex
\documentclass[sigconf,anonymous,review]{acmart}
```

The template is pinned to `acmart` v2.19 (2026-06-27). The latest published Web Conference
Research Track instructions allow eight main-content pages and up to twelve pages including
references and an optional appendix. The ICLR manuscript remains independent under `../ICLR/`.

## Research question

**How can GNNs safely leverage fallible LLM semantic evidence to remain robust against adversarial
graph and text manipulation?**

## Build

Set `WWW/main.tex` as the Overleaf main document.
